SURVIVAL-ANALYSIS INTERPRETATION
------------------------------------------------------------------
Telecom context                 Survival-analysis context
Customer churns                Event / death
Customer stays                 Surviving / event not observed
tenure_in_months               Survival or follow-up time
churn_label = Yes              Event occurred (recommended event code = 1)
churn_label = No               Right-censored / no churn observed (recommended event code = 0)

Important statistical note:
In survival analysis, a customer with churn_label = No is normally treated as
RIGHT-CENSORED at tenure_in_months. This means the customer was still active
when observation ended; it does not mean the customer can never churn later.

Suggested R-style survival object:
  Surv(time = tenure_in_months, event = churn_event)
where:
  churn_event = 1 if churn_label == 'Yes'
  churn_event = 0 if churn_label == 'No'
